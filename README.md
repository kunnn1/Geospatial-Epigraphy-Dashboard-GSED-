# Geospatial-Epigraphy-Dashboard-GSED-
A geospatial dashboard of Judeo-Christian monotheist (ḥanīf) inscriptions in pre-Islamic Arabia between the 5th and 7th century CE. Pre-dominately modeled from Lindstedt's mapping from his "Muḥammad and His Followers in Context: The Religious Map of Late Antique Arabia"
